# LangtonsAnt.jl

## About Langston's ant

<a href="https://en.wikipedia.org/wiki/Langton%27s_ant">Langton's ant (wilipedia)</a>


## Usage

usage: LangtonsAnt.jl [-g GRID-SIZE] [-d DIRECTION] [-s STEPS]
                      [-o OUT] [-h]

optional arguments:
  -g, --grid-size GRID-SIZE  
        grid size (type: Int64, default: 200)  
  
  -d, --direction DIRECTION  
        ant direction: 0: up, 1: right, 2: down, 3:left (type: Int64, default: 0)  
  
  -s, --steps STEPS  
        step number (type: Int64, default: 12000)  
  
  -o, --out OUT  
        output file name (default: "langtons_ant")  
  
  -h, --help  
        show this help message and exit
